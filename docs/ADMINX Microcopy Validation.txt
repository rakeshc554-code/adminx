3.3 Focus Order (Keyboard Navigation)

Desktop & Web:
text

1. Skip to Main Content Link (hidden until focused)
2. Sidebar (if open)
   a. Logo/Home
   b. Navigation Items (Dashboard → Settings)
   c. Logout
3. Main Content Area (Top to Bottom)
   a. Top Bar (Search → Notifications → Profile)
   b. Page Header (Title → Actions)
   c. Filters & Tabs
   d. Main Content (Table/List/Cards)
   e. Pagination
4. Modals & Popups
   a. Trap focus inside modal
   b. Close button first
   c. Form fields
   d. Action buttons (Cancel → Save)
   e. Focus returns to trigger element on close
5. Toast Notifications (auto-dismiss, but focusable if persistent)

Mobile (Touch + VoiceOver/TalkBack):

    Natural flow: Top to bottom, left to right.

    Focusable elements: Buttons, Inputs, Links, Interactive Cards.

    Swipe gestures for navigation (TalkBack/VoiceOver standard).
