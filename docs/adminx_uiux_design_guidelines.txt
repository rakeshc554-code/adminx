# ADMINX — UI/UX Design Guidelines

**Version:** 1.0  
**Date:** June 2026  
**Document Type:** Design Guidelines

---

## 1. Design Philosophy

### 1.1 Core Principles

| Principle | Description |
| :--- | :--- |
| **Necessity-First** | Every feature should proactively eliminate work for the user. Automate what can be automated. |
| **Simplicity** | Minimal learning curve; intuitive navigation. Users should feel confident within minutes. |
| **Consistency** | Uniform design language across all platforms (Mobile, Web, Desktop). |
| **Accessibility** | WCAG 2.2 AA level basics — sufficient contrast, scalable text, keyboard navigable. |
| **Mobile-First** | Design for small screens first, then scale up. All features must be usable on mobile. |

### 1.2 Tone & Voice

- **Professional** but not intimidating
- **Modern** and intelligent
- **Helpful** — proactive suggestions, not overwhelming
- **Trustworthy** — data security and privacy always communicated

### 2.2 Typography

| Element | Font | Size | Weight | Line Height |
| :--- | :--- | :--- | :--- | :--- |
| **H1 — Page Titles** | Inter | 28px | Bold (700) | 1.2 |
| **H2 — Section Headers** | Inter | 22px | Semibold (600) | 1.3 |
| **H3 — Card Headers** | Inter | 18px | Semibold (600) | 1.4 |
| **Body — Regular** | Inter | 16px | Regular (400) | 1.5 |
| **Body — Small** | Inter | 14px | Regular (400) | 1.5 |
| **Caption** | Inter | 12px | Regular (400) | 1.4 |
| **Button / Action** | Inter | 16px | Medium (500) | 1.0 |

**Fallback Font:** System default sans-serif on all platforms.

### 2.3 Iconography

- Use **Lucide Icons** (open-source, consistent style) or **Material Icons**.
- Icon size: 20px for inline, 24px for standalone buttons, 32px for navigation.
- Color: Neutral 700 for default, Primary for active.

## 3. Layout & Spacing

### 3.1 Grid System

- **Base unit:** 8px
- **Spacing scale:** 4, 8, 12, 16, 24, 32, 48, 64, 80, 96
- **Breakpoints:**
  - Mobile: <= 480px
  - Tablet: 481–768px
  - Desktop: 769–1200px
  - Wide: > 1200px

### 3.2 Component Spacing

| Component | Padding | Margin (Bottom) |
| :--- | :--- | :--- |
| Page Container | 16px (mobile), 24px (desktop) | N/A |
| Card | 16px | 16px |
| Form Group | 8px (between items) | 16px |
| Button | 8px 16px | 16px |
| List Item | 12px 16px | 2px |

## 4. Navigation Patterns

### 4.1 Mobile (Bottom Tab Bar)

- 5 tabs maximum: **Dashboard, Customers, Invoices, Products, More**
- Active tab: Primary color icon + label
- Inactive: Neutral 400 icon + label

### 4.2 Desktop (Sidebar Navigation)

- Collapsible sidebar with icons + labels
- Sections: Dashboard, Sales (Invoices, Payments), Inventory, Customers, Employees, Reports, Settings

### 4.3 Web (Top Navigation + Dropdowns)

- Top bar with brand logo, search, user profile
- Dropdown menus for main sections

### 4.4 Breadcrumbs

- Show on desktop and web for deep navigation (e.g., Home > Customers > Ramesh > Ledger)

## 5. Key Screens & Components

### 5.1 Dashboard (Home)

- **Top**: Welcome message + date
- **Key Metrics Cards**: Total Sales, Outstanding Balance, Low Stock Count, Number of Invoices (last 30 days)
- **Recent Activity**: List of recent transactions and invoices
- **Quick Actions**: "New Invoice", "Add Customer", "Record Payment"
- **AI Insight**: Small card showing a proactive tip (e.g., "Ramesh's payment is overdue by 3 days. Send reminder?")

### 5.2 Customer List

- **Search Bar**: Global search with AI-powered suggestions
- **Filter/Sort**: By name, balance (high/low), recent transaction
- **List Items**: Avatar (initials), name, phone, balance with color (green for positive, red for negative)

### 5.3 Customer Ledger

- **Header**: Customer name, phone, total balance
- **Transaction List**: Chronological (most recent first) with amount, type, description, date
- **Add Transaction**: Floating button opens bottom sheet with amount, type, description, optional invoice link
- **Send Reminder**: Button at top right

### 5.4 Invoice Creation

- **Step-by-step wizard**:
  1. Select Customer (search/autocomplete)
  2. Add Items (search products, add custom)
  3. Review totals (subtotal, GST, grand total)
  4. Send/Share (WhatsApp, Email, SMS)
- **AI Suggestion**: When typing product name, show recent prices and quantities.

### 5.5 Inventory Management

- **Product List**: Thumbnail (or placeholder), name, SKU, price, stock quantity, low stock badge
- **Add/Edit Product**: Form with fields: name, SKU, barcode (auto-generate), price, cost, quantity, reorder level, expiry date (optional)
- **Barcode Scanner**: Camera view for scanning

### 5.6 Reports

- **Filterable by date range**
- **Export options**: PDF, Excel, CSV
- **Charts**: Bar/line charts for sales trends, expense breakdown (pie chart)

### 5.7 AI Chat Assistant

- Floating icon on bottom-right (mobile) or sidebar (desktop)
- Opens as a chat bubble
- User types natural language; AI responds with data from local database
- Examples: "Show my top 5 customers", "What were my sales last week?", "How much GST did I pay?"

## 6. Responsive Behavior

| Component | Mobile | Tablet | Desktop |
| :--- | :--- | :--- | :--- |
| Navigation | Bottom tab bar | Sidebar + top bar | Sidebar + top bar |
| Dashboard Cards | Stack vertically | 2-column grid | 3–4 column grid |
| Forms | Full width | 2-column layout | 3-column layout |
| Tables | Horizontal scroll | Full width with sticky first column | Full width |

---

## 7. Accessibility

- **Contrast Ratio**: Minimum 4.5:1 for text (WCAG AA)
- **Touch Targets**: Minimum 44px for interactive elements (mobile)
- **Screen Reader Support**: All icons have aria-label; form fields have <label>
- **Focus States**: Visible outline on interactive elements
- **Reduced Motion**: Respect user's prefers-reduced-motion setting

---

## 8. Dark Mode

- Automatic based on system preference; override in settings
- **Colors**:
  - Background: #121212
  - Surface: #1E1E1E
  - Text: #EEEEEE
  - Primary: #4F8BFF (lighter variant)
  - Borders: #333333

## 9. Micro-Interactions

| Action | Animation |
| :--- | :--- |
| Button click | Ripple effect (Material) |
| Page transition | Fade + slide (left/right) |
| Card expand | Spring-like easing |
| Loading | Skeleton screens (not spinners) |
| Success/Failure | Toasts with color-coded feedback |
| AI response | Typing indicator (three dots) |
