1. PROJECT OVERVIEW

AdminX is a cross-platform (Android, iOS, Web, Desktop) business management application built with Kotlin Multiplatform (KMP). This document provides everything a developer needs to set up their local environment, understand the codebase structure, and follow project standards.

Auth/Sync               | Firebase (Auth, Firestore, FCM)

Payments                | Razorpay SDK
PDF Generation          | Apache PDFBox 3.0.3
Barcodes                | ZXing 3.5.3

3. LOCAL DEVELOPMENT SETUP

3.1 Prerequisites

Tool                    | Version     | Download/Install
------------------------|-------------|------------------------------------------
JDK                     | 17+         | Adoptium (https://adoptium.net/)
Android Studio          | Hedgehog+   | https://developer.android.com/studio
Xcode                   | 15+ (macOS) | Mac App Store
KMP Plugin              | Latest      | Android Studio > Plugins
Node.js                 | 18+         | https://nodejs.org/
Git                     | Latest      | https://git-scm.com/
Firebase CLI            | Latest      | npm install -g firebase-tools

3.2 Clone & Build

Step 1: Clone the repository
git clone https://github.com/your-org/adminx.git
cd adminx

Step 2: Set up environment variables (copy from .env.example)
cp .env.example .env
Edit .env with your Firebase keys

Step 3: Build the shared KMP library
./gradlew build

Step 4: Run Android App (Android Studio or CLI)
./gradlew :androidApp:installDebug

Step 5: Run iOS App (macOS only - open in Xcode)
open iosApp/iosApp.xcworkspace
Click Run button in Xcode

Step 6: Run Desktop App (Windows/macOS)
./gradlew :desktop:run

Step 7: Run Web App (Development server)
./gradlew :web:run
Open http://localhost:8080

3.3 Firebase Configuration

1. Create a project in Firebase Console (https://console.firebase.google.com/).
2. Enable Authentication (Email/Password + Phone).
3. Enable Firestore and set up security rules (see firestore.rules in repo).
4. Download google-services.json (Android) and GoogleService-Info.plist (iOS).
5. Place them in the respective app/ folders.
6. Enable Firebase Cloud Messaging (for push notifications).
7. Enable Google Cloud Storage (for backups).


4. CODING STANDARDS & LINTING

4.1 Kotlin (Shared, Android, Desktop)

- Style: Follow the official Kotlin Coding Conventions.
- Naming:
  - Classes/Interfaces: PascalCase (e.g., CustomerRepository)
  - Functions/Variables: camelCase (e.g., getOutstandingBalance)
  - Constants: UPPER_SNAKE_CASE (e.g., MAX_RETRY_COUNT)
  - Suspend Functions: Name should indicate async (e.g., fetchCustomers)
- Linting: Use Detekt
  Command: ./gradlew detekt
- Formatting: Use Ktlint
  Command: ./gradlew ktlintFormat
- Rule of Thumb: Maximum line length = 120 characters.

4.2 Swift (iOS specific)

- Follow Swift API Design Guidelines.
- Use let for constants, var for variables.
- Mark public only for exposed KMP interfaces.

4.3 TypeScript/JavaScript (Web specific)

- Use ESLint with Airbnb base config.
- Use Prettier for automatic formatting.
- React components must follow functional component structure with hooks.

6. TROUBLESHOOTING GUIDE

Issue                                           | Cause                                    | Solution
------------------------------------------------|------------------------------------------|----------------------------------------------------
Gradle build fails on macOS                     | Missing Xcode command line tools         | Run xcode-select --install
Android Emulator won't start                    | Intel HAXM missing or virtualization     | Enable VT-x in BIOS. Install HAXM.
iOS build fails: "No such module"               | CocoaPods not installed or outdated      | Run sudo gem install cocoapods and pod install in iosApp folder.
Web build stuck at 80%                          | Node.js memory limit reached             | Run export NODE_OPTIONS="--max-old-space-size=4096"
Firebase Auth returns "Network Error"           | Missing google-services.json or plist    | Ensure files are correctly placed in androidApp/app/ and iosApp/.
AI Model crashes on startup                     | Insufficient RAM to load 2GB model       | Use smaller Llama 3.2 1B for testing on low-RAM devices.
Sync conflicts are not resolving                | Server timestamp vs local timestamp      | Check if version field is incrementing correctly.
WhatsApp message fails to send                  | Invalid phone number format              | Ensure number includes country code (e.g., +91 for India).

8. PRE-COMMIT HOOKS (GIT HOOKS)

To enforce code quality before pushing, set up pre-commit hooks.

Step 1: Add to build.gradle.kts
tasks.register("preCommit") {
    dependsOn("ktlintFormat", "detekt", "test")
}

Step 2: Run manually before push
./gradlew preCommit

Optional: Husky Setup (for automatic hooks)
npm install --save-dev husky
npx husky install
npx husky add .husky/pre-commit "./gradlew preCommit"
