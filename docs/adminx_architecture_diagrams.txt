## 2. Offline-First Sync Flow

sequenceDiagram
    participant User
    participant App
    participant LocalDB
    participant SyncQueue
    participant Cloud

    User->>App: 📝 Performs action (Add Invoice/Customer)
    App->>LocalDB: ✍️ Write data locally (Immediate)
    LocalDB-->>App: ✅ Success
    App->>User: 🎉 Show success (Instant, offline)
    
    App->>SyncQueue: 📤 Add change to queue (with timestamp)
    
    Note over App,LocalDB: 🔌 USER IS OFFLINE (Works perfectly)

    SyncQueue->>SyncQueue: ⏳ Waiting for network...
    SyncQueue->>Cloud: 🌐 Internet detected - Upload changes
    Cloud-->>SyncQueue: ✅ Acknowledge receipt
    SyncQueue->>LocalDB: 📌 Mark changes as "synced"
    LocalDB-->>App: Sync complete


## 3. On-Device AI Processing (Privacy-First)

sequenceDiagram
    participant User
    participant App
    participant Router
    participant LocalSLM as 🧠 Local SLM<br>(Phi-3/Llama)
    participant LocalDB

    User->>App: 💬 "Show Ramesh's pending balance"
    App->>Router: Route query
    Note over Router: 🔍 Analyzes: Simple lookup vs Complex reasoning?
    
    alt Simple Query (Data Retrieval)
        Router->>LocalSLM: Execute local inference
        LocalSLM->>LocalDB: Query database
        LocalDB-->>LocalSLM: Return balance (₹15,000)
        LocalSLM-->>App: Formatted response
    end
    
    alt Complex Query (Forecasting)
        Router->>LocalSLM: Execute complex inference
        LocalSLM->>LocalDB: Fetch 6 months history
        LocalSLM->>LocalSLM: Analyze & Predict
        LocalSLM-->>App: 📈 "Cash flow may dip in July"
    end
    
    App->>User: 📱 Display answer (0 server calls made!)
    
    Note over User,LocalDB: 🔒 Data stays on device. No API costs.

## 6. Invoice State Diagram

stateDiagram-v2
    [*] --> Draft: 🆕 Create Invoice
    
    Draft --> Sent: ✉️ Share / Send Invoice
    Draft --> Cancelled: 🗑️ User Deletes Draft
    
    Sent --> Paid: ✅ Payment Received (Full Amount)
    Sent --> Overdue: ⏰ Due Date Passes (Auto-Transition)
    Sent --> Cancelled: 🗑️ User Cancels Sent Invoice
    
    Overdue --> Paid: 💵 Partial/Late Payment Received
    Overdue --> Overdue_Reminder: 🔔 Reminder Sent (Auto)
    Overdue_Reminder --> Overdue: ⏳ No Action (Loop)
    Overdue_Reminder --> Paid: 💵 Payment Made
    
    Paid --> Paid_Partial: 💸 Partial Payment Received
    Paid_Partial --> Paid: ✅ Remaining Amount Received
    Paid_Partial --> Overdue: ⏰ Balance Due Date Passes
    
    Cancelled --> [*]: 🗑️ End of Life
    
    note right of Draft
        🧠 AI Suggests items & prices
        💾 Auto-saved locally
    end note
    
    note right of Sent
        📨 WhatsApp/Email sent to customer
        📊 Added to outstanding balance
    end note
    
    note right of Overdue
        🔔 Auto-sends reminders at 3, 7, 15 days
        📈 Shows in dashboard alerts
    end note
    
    note right of Paid
        ✅ Removed from outstanding balance
        📄 E-receipt auto-generated
        🧾 GST return data updated
    end note

## 11. Payment Gateway Sequence (Razorpay)

sequenceDiagram
    autonumber
    participant User as 👤 Customer
    participant App as 📱 AdminX App
    participant Backend as ⚙️ AdminX Backend
    participant Razorpay as 💳 Razorpay API
    participant Webhook as 📨 Razorpay Webhook
    participant InvoiceDB as 🗄️ Invoice Database

    User->>App: 📄 Clicks "Pay Now" on Invoice
    App->>Backend: 🚀 POST /payment/create-order<br>{invoiceId, amount, currency}
    
    Backend->>Backend: 🔐 Generate unique receipt_id
    Backend->>Razorpay: 💳 POST /orders<br>{amount, currency, receipt}
    Razorpay-->>Backend: ✅ Returns {order_id, key_id}
    
    Backend-->>App: 📦 Return order_id & key_id
    App->>User: 📲 Opens Razorpay Checkout UI
    
    User->>Razorpay: 💵 Select payment method (UPI/Card/NB)
    Razorpay->>User: 🔐 Redirects to Bank / UPI App
    User->>Razorpay: ✅ Authorizes Payment
    
    Razorpay->>Webhook: 📨 POST /webhook/payment-confirmed<br>{order_id, payment_id, signature}
    
    Webhook->>Backend: 🔐 Verify webhook signature
    Backend->>Backend: ✅ Validate payment_status == 'captured'
    
    Backend->>InvoiceDB: ✍️ UPDATE invoices SET status = 'PAID'
    InvoiceDB-->>Backend: ✅ Status Updated
    
    Backend->>Razorpay: ✅ Acknowledge Webhook (200 OK)
    
    Razorpay->>User: 🔄 Redirect back to App (with success param)
    User->>App: 📱 Return from Payment UI
    
    App->>Backend: 🔍 GET /payment/verify/{order_id}
    Backend-->>App: ✅ Payment Verified & Invoice Paid
    
    App->>User: 🎉 Display "Payment Successful" screen
    App->>User: 📨 Send digital receipt via WhatsApp/Email

## 15. Database Migration Strategy

flowchart TD
    A[🚀 App Starts<br>Version 2.0.0] --> B[🔍 Check Local DB Version<br>PRAGMA user_version;]
    
    B --> C{Compare Versions}
    
    C -->|DB Version == App Version| D[✅ Load Database Normally<br>No Migration Needed]
    
    C -->|DB Version < App Version| E[⚙️ Start Migration Engine<br>with Room SQLiteOpenHelper]
    
    subgraph MIGRATION_PIPELINE[🛠️ Migration Pipeline]
        direction TB
        M1[📋 Get Current Version: v1]
        M1 --> M2{Check Upgrade Path}
        
        M2 -->|v1 -> v2| Step1[🔧 Run: Migration_1_to_2]
        M2 -->|v2 -> v3| Step2[🔧 Run: Migration_2_to_3]
        M2 -->|v1 -> v3| Step3[🔧 Run: Migration_1_to_3<br>(Cumulative)]
        
        Step1 --> S1[📝 SQL: ALTER TABLE customers<br>ADD COLUMN credit_limit REAL DEFAULT 0;]
        Step2 --> S2[📝 SQL: CREATE TABLE invoice_items<br>...; ALTER TABLE invoices ADD ...;]
        Step3 --> S3[📝 Data Transformation<br>Java/Kotlin loop to populate new columns]
        
        S1 --> V1[📌 Update PRAGMA user_version = 2]
        S2 --> V2[📌 Update PRAGMA user_version = 3]
        S3 --> V3[📌 Update PRAGMA user_version = 3]
    end
    
    D --> F[✅ Database Ready]
    V1 --> F
    V2 --> F
    V3 --> F
    
    C -->|DB Version > App Version| E1[❌ Fatal Error<br>Downgrade not allowed<br>Must re-install or restore backup]

    subgraph SAFETY_NET[🛡️ Safety / Rollback]
        N1[📤 Before Migration:<br>Export full DB to /backups/]
        N2[🧪 Run Migration in Transaction<br>BEGIN TRANSACTION; ...; COMMIT;]
        N3[❌ If Exception occurs:<br>ROLLBACK; Restore from backup]
