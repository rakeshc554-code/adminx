1. ROLE-BASED ACCESS CONTROL (RBAC) — PERMISSION MATRIX

This matrix defines exactly what each user role can Read (R), Write (W), Delete (D), and Export (E).
Note: The Owner role is the highest privilege; Viewer is the lowest.

Customers (Khata)                | R,W,D,E| R,W,D,E| R,W,E      | R,W,E   | R,W       | R
Customer Ledger (Transactions)   | R,W,D  | R,W,D  | R,W        | R,W     | R,W       | R

RULES OF THE MATRIX:
- "HIDDEN" means the menu option or button is completely invisible to that role.
- "D" (Delete) always requires a secondary confirmation modal.
- "E" (Export) is disabled for users on the Free Plan (available only in Paid tiers).

3. DATA RETENTION & ARCHIVING POLICY

AdminX follows the Indian Income Tax Act (1961) guidelines, which mandate retaining financial records for 8 years from the end of the relevant assessment year.

3.1 Local Device Retention
- Active Data: All data (Customers, Transactions, Invoices) remains on the device indefinitely unless the user manually deletes it.
- Performance Optimization: If the device exceeds 50,000 transactions, the app will prompt: "Archive older than 2 years?"

3.2 Automatic Archiving (Cloud)
- What: Invoices older than 3 years will be compressed into .zip archives.
- How: Monthly batch job runs on the 1st of every month.
- Impact: Archived data is removed from the main invoices table and moved to an archived_invoices bucket. It is still searchable via the "Advanced Search" toggle (with a 2-3 second delay).

3.3 User-Initiated Purging
- Soft Delete: Customers/Invoices deleted by the user are moved to a "Trash" folder for 30 days.
- Hard Delete: After 30 days, or if the user clicks "Empty Trash", the data is irreversibly purged from SQLite and the cloud backup.

3.4 Backup Retention
- Daily Backups: Stored for 30 days.
- Weekly Backups: Stored for 6 months.
- Monthly Backups: Stored for 7 years (Compliance).

5. ROLE-BASED WORKFLOWS (SUMMARY)

5.1 Sales Rep Workflow (The "Invoice Creator")
Goal: Create and share an invoice as fast as possible, with zero access to costs or payroll.

Step 1: Log In -> Dashboard (Sees: Sales KPI, Customers, Products)
Step 2: Click 'Create Invoice'
Step 3: Search / Select Customer (or Add New with Name + Phone only)
Step 4: Add Products and Quantities
Step 5: System Calculates Total (Cost Price is HIDDEN)
Step 6: Share via WhatsApp/Email
Step 7: Invoice Marked as 'Sent'. End of flow.

5.2 Accountant Workflow (The "Financial Controller")
Goal: Reconcile bank statements, file GST, and run P&L reports.

Step 1: Log In -> Dashboard (Sees: Expenses, Reports, Bank Rec.)
Step 2: Choose Action:
  - Reconcile Bank: Upload CSV -> AI Auto-Matches -> Manually Review Unmatched
  - GST Filing: Open GST Reports -> View GSTR-1, 3B, 9 -> Export JSON for CA
  - P&L / Balance Sheet: Select Date Range -> View -> Export PDF
Step 3: End of flow.

5.3 Manager Workflow (The "Operations Lead")
Goal: Oversee inventory, manage low stock, and ensure team performance.

Step 1: Log In -> Dashboard (Sees: Inventory, Stock Alerts, Team Activity)
Step 2: Choose Action:
  - Check Inventory: View Product List -> Low Stock Badge -> Create Purchase Order
  - Track Team: View Employee List -> View Attendance/Performance -> Assign Task
Step 3: End of flow.

5.4 Admin Workflow (The "Super User")
Goal: Manage users, assign roles, handle payroll, and manage backups.

Step 1: Log In -> Dashboard (Sees: ALL features + Settings menu)
Step 2: Choose Action:
  - Manage Users: Go to 'Manage Users' -> Invite New User -> Assign Role
  - Run Payroll: Open Payroll Module -> Select Month -> Calculate Salaries -> Generate Payslips
  - Backup: Open Settings > Backup -> Create Full Backup or Restore
Step 3: End of flow.

5.5 Viewer Workflow (The "Read-Only" Auditor)
Goal: View data only. Used for external CAs or investors. Zero write permissions.

Step 1: Log In -> Dashboard (All Widgets Visible, Buttons Greyed Out)
Step 2: Navigate:
  - Check Ledger: Open Customers -> View Ledger (Add Transaction button is DISABLED)
  - Check Reports: Open Reports -> View P&L / Balance Sheet -> Export PDF (Allowed)
  - Check Inventory: Open Products -> View Stock & Prices (Add Product button is DISABLED)
Step 3: End of flow.
